CloudMigrator Privacy Policy
CloudMigrator プライバシーポリシー

Effective date / 発効日: 2026-08-08

このポリシーは、CloudMigrator の CLI、Dashboard、および MSIX 版に適用されます。

This policy applies to the CloudMigrator CLI, Dashboard, and MSIX package.

1. 開発者が収集しない情報 / Information We Do Not Collect

日本語

CloudMigrator の開発者は、移行データを受け取る開発者運営のバックエンドを提供していません。アプリにアカウント登録、広告、行動分析、テレメトリー、または販売目的のデータ収集機能はありません。

サポートやリリース情報の GitHub ページは、ユーザーがリンクを選択したときにブラウザーで開きます。GitHub 側の処理には GitHub のプライバシーポリシーが適用されます。

English

The CloudMigrator developer does not operate a backend that receives migration data. The app does not provide account registration, advertising, behavioral analytics, telemetry, or data sales.

Support and release pages on GitHub are opened in a browser when the user chooses a link. GitHub's privacy policy applies to GitHub's processing.

2. アプリが扱う情報 / Information Processed by the App

日本語

  • 移行元として設定した OneDrive のファイル名、パス、サイズ、更新日時などのメタデータ。
  • 移行先として選択した SharePoint Online または Dropbox へ送信するファイルと、転送に必要なメタデータ。
  • ローカル設定、転送状態データベース、スキップリスト、キャッシュ、進捗・エラーログ。

これらは移行を実行するためにユーザーの端末上で処理されます。ローカルに保存される場所はアプリの設定に従います。認証情報は Windows Credential Manager または環境変数から読み取られ、ログへ意図的に出力しない設計です。

English

  • File names, paths, sizes, modified times, and other metadata from the configured OneDrive source.
  • Files and metadata required to send the migration to the selected SharePoint Online or Dropbox destination.
  • Local configuration, transfer state databases, skip lists, caches, progress data, and error logs.

This information is processed on the user's device to perform the migration and is stored in locations controlled by the app configuration. Credentials are read from Windows Credential Manager or environment variables and are not intentionally written to logs.

3. 外部サービスへの送信 / Transfers to Third-Party Services

日本語

ユーザーが移行を開始した場合、アプリは設定された認証情報を使って Microsoft Graph 経由で OneDrive を読み取り、選択された SharePoint Online または Dropbox へファイルを送信します。これはアプリの中心機能であり、開発者への送信ではありません。各サービスによるデータの取り扱いには、各サービスのポリシーが適用されます。

  • Microsoft Privacy Statement
  • Dropbox Privacy Policy
  • GitHub Privacy Statement

English

When the user starts a migration, the app uses the configured credentials to read the OneDrive source through Microsoft Graph and send files to the selected SharePoint Online or Dropbox destination. This is the app's core function and is not a transfer to the developer. The policies of each service govern its handling of the data.

4. 保存期間と削除 / Retention and Deletion

日本語

開発者は移行データを保持しません。端末上の設定、状態 DB、キャッシュ、ログの保存期間はユーザーの設定・運用に委ねられます。移行完了後に不要なローカルデータを削除する場合は、アプリを停止してから設定したデータディレクトリを確認してください。送信先サービス上のデータは、ユーザーまたは組織が各サービスの機能で管理します。

English

The developer does not retain migration data. Retention of local configuration, state databases, caches, and logs is controlled by the user's configuration and operations. After stopping the app, users may review and delete unneeded local data. Data in the destination service is managed by the user or organization through that service.

5. セキュリティ / Security

日本語

認証情報をソースコードや Store Listing に含めないでください。Windows Credential Manager または環境変数を使用し、ログやスクリーンショットに秘密情報を表示しないでください。外部サービスのアクセス権、保持期間、監査設定は利用する Microsoft 365 / Dropbox 環境の管理者が確認してください。

English

Do not put credentials in source code or Store listing data. Use Windows Credential Manager or environment variables, and keep secrets out of logs and screenshots. Administrators of the Microsoft 365 or Dropbox environment should review access, retention, and audit settings for the services they use.

6. 変更とお問い合わせ / Changes and Contact

日本語

このポリシーを変更した場合は、このページの発効日を更新します。お問い合わせや問題報告は GitHub Issues から送信してください。

English

If this policy changes, the effective date on this page will be updated. For questions or issue reports, contact us through GitHub Issues.
